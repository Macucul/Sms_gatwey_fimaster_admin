FastAPI, Redis-backed event gateway for FiMaster

This service provides secure ingestion endpoints for events generated by the EA (MetaTrader Expert Advisor) and administrative user creation APIs used by the sms_gatwey_fimaster_admin system.

Features
- HMAC-SHA256 signature verification for incoming requests
- Canonical event ID generation when incoming payload lacks event_id
- Idempotency using Redis (SETNX) to avoid duplicates
- Optional persistence to Firebase Realtime Database (configured by env vars)
- Lightweight POST /events and POST /users endpoints

Environment variables (examples)
- REDIS_URL=redis://redis:6379/0
- GATEWAY_SECRET=replace_with_strong_secret
- FIREBASE_BASE=https://your-db.firebaseio.com
- FIREBASE_AUTH=<firebase-db-secret>
- ADMIN_TOKEN=<admin-token-for-users-endpoint>
- IDEMPOTENCY_TTL=604800

Run (development)
- pip install -r requirements.txt
- export REDIS_URL=redis://localhost:6379/0
- uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Docker
- Build and run using the provided Dockerfile and optionally docker-compose.yaml
